
## Build a basic version of PayTM

This project is a mini-application inspired by popular digital payment platforms like Paytm and Venmo. The goal was to create a basic yet functional version of a peer-to-peer payment app that enables users to send and receive money seamlessly.

Environment: (Frontend: React.js), (Backend: Node.js with Express), (Database: MongoDB), CSS

Accomplishment:
1. User Registration and Login: Users can create accounts, log in, and securely manage their sessions with JWT authentication.
2. Money Transfers: The core feature allows users to transfer funds to others by inputting the recipient's details and the amount to be sent.
3. Transaction History: Users can view their past transactions, which are logged and displayed in their account dashboard.
4. User Profiles: Each user can have a profile page displaying their balance and basic details.
5. Demonstrate the ability to handle authentication and authorization using JWT tokens for secure access control.
6. Practical application that mimics real-world payment platforms, focusing on the user experience, security, and efficient transaction management.
